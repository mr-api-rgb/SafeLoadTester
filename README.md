# SafeLoadTester 🚀

**SafeLoadTester** یک ابزار تست فشار و بار برای بررسی عملکرد وب‌سایت‌ها و سرویس‌های HTTP است که از طریق ترمینال اجرا می‌شود.

این پروژه برای تست سرویس‌هایی طراحی شده که کاربر **مجوز تست آن‌ها را دارد** و دارای محدودیت‌های داخلی برای جلوگیری از ایجاد ترافیک کنترل‌نشده است.

## ✨ امکانات

* 🌐 دریافت آدرس سایت از طریق ترمینال
* 👥 تعیین تعداد کاربران همزمان
* 📊 تعیین Requests Per Second
* ⏱️ تعیین مدت زمان تست
* ⌛ تعیین Timeout درخواست‌ها
* ✅ شمارش درخواست‌های موفق
* ❌ شمارش درخواست‌های ناموفق
* 📈 محاسبه نرخ موفقیت
* ⚡ محاسبه RPS واقعی
* 🕐 محاسبه میانگین زمان پاسخ
* 📉 نمایش کمترین و بیشترین زمان پاسخ
* 🛡️ دارای محدودیت داخلی برای کنترل فشار

## 🧰 تکنولوژی‌ها

* Python
* asyncio
* HTTPX

## ⚙️ نصب

ابتدا مخزن را دریافت کنید:

```bash
git clone YOUR_REPOSITORY_URL
cd SafeLoadTester
```

سپس وابستگی‌ها را نصب کنید:

```bash
python -m pip install -r requirements.txt
```

## ▶️ اجرا

برنامه را اجرا کنید:

```bash
python main.py
```

سپس اطلاعات تست را وارد کنید:

```text
Target URL: https://example.com
Concurrent Users: 5
Requests Per Second: 10
Test Duration (seconds): 10
Request Timeout (seconds): 5
```

## 🛡️ محدودیت‌ها

نسخه اول پروژه دارای محدودیت‌های داخلی است:

```text
Maximum Users      : 50
Maximum RPS        : 100
Maximum Duration   : 60 seconds
Maximum Timeout    : 10 seconds
```

این محدودیت‌ها برای جلوگیری از ایجاد بار کنترل‌نشده روی سرویس مقصد در نظر گرفته شده‌اند.

## ⚠️ مسئولیت استفاده

این ابزار صرفاً برای **Load Testing و Stress Testing مجاز** طراحی شده است.

قبل از تست یک سرویس عمومی، مطمئن شوید که مالک یا مسئول آن سرویس اجازه انجام تست را داده است.

استفاده از این ابزار برای ایجاد اختلال، از کار انداختن یا ارسال ترافیک مخرب به سرویس‌هایی که مجوز تست آن‌ها را ندارید، مورد نظر این پروژه نیست.
